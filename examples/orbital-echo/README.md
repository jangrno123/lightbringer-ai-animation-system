# ORBITAL ECHO example

This directory contains the sanitized input and representative machine-readable output used in the LIGHTBRINGER working-product demo.

- `input-screenplay.ko.txt` — approved Korean screenplay source;
- `run-summary.json` — stage counts and completion state;
- `shot-output.sample.json` — one editable shot/timing record;
- `prompt-master.sample.json` — shared prompt rules and one compiled shot master.

See the illustrated [demo case study](../../docs/DEMO_CASE_STUDY.md).
