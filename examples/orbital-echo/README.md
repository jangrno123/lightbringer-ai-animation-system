# ORBITAL ECHO example / 공개 예제

This directory contains the sanitized input and representative machine-readable output used in the LIGHTBRINGER working-product demo.

- `input-screenplay.ko.txt` — approved Korean screenplay source / 승인 한국어 대본;
- `input-screenplay.en.txt` — approved English translation / 승인 영문 대본;
- `run-summary.json` — stage counts and completion state;
- `shot-output.sample.json` — one editable Korean shot/timing record;
- `shot-output.sample.en.json` — the same editable shot/timing record in English;
- `prompt-master.sample.json` — shared Korean/English prompt rules and both compiled masters.

See the illustrated [English case study](../../docs/DEMO_CASE_STUDY.md) or [한국어 실행 사례](../../docs/DEMO_CASE_STUDY.ko.md).
