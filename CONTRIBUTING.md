# Contributing

LIGHTBRINGER welcomes production-focused feedback from artists, directors, producers, engineers, researchers, and model providers.

## Valuable contributions

- a clearly described production bottleneck;
- a reproducible failure and recovery case;
- improvements to the workflow or architecture;
- vendor-neutral integration patterns;
- production metrics and evaluation methods;
- accessibility and usability feedback for long-form shot review;
- translations and terminology corrections.

## Please avoid

- uploading copyrighted or confidential production media;
- posting API keys, tokens, private URLs, or user data;
- presenting unverified cost or quality improvements as fact;
- turning workflow discussions into model fan debates;
- requesting access to private client or production data.

## Issue format

Include:

1. production role and context;
2. current workflow;
3. exact bottleneck;
4. frequency and impact;
5. current workaround;
6. proposed change;
7. a measurable success condition.

## Pull requests

- Keep one conceptual change per pull request.
- Explain which production stage changes.
- Update diagrams and Korean documentation when relevant.
- Do not add client-specific names, media, or story content.
- Confirm that all contributed material may be published under this repository's license.

## Conduct

Participation is governed by [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
